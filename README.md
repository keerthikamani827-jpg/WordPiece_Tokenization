# WordPiece Tokenization

This project implements the **WordPiece Tokenization algorithm from scratch using Python**.

WordPiece is a subword tokenization technique commonly used in Natural Language Processing (NLP). It divides words into smaller subword tokens and uses the `##` prefix for continuation tokens.

This project demonstrates how WordPiece Tokenization works step by step without using a pre-built tokenizer library.

## Dataset

The project uses the following word frequency dataset:

* play: 4
* player: 2
* playing: 3
* playful: 2
* code: 3
* coder: 2
* coding: 2
* computer: 3

## Project Workflow

The implementation follows these steps:

1. Store the word frequency data
2. Perform the initial WordPiece split
3. Create the initial vocabulary
4. Calculate token frequencies
5. Calculate pair frequencies
6. Calculate WordPiece scores
7. Select the best pair
8. Merge the selected pair
9. Repeat the merging process
10. Generate the final vocabulary
11. Tokenize the test word
12. Handle unknown words using `[UNK]`
13. Convert tokens into token IDs

## Example

For the word:

```text
playing
```

The initial split is:

```text
p ##l ##a ##y ##i ##n ##g
```

Frequently occurring token pairs are merged during training to create larger subword tokens.

The final tokenization depends on the vocabulary learned during the training process.

## WordPiece Score

The score is calculated using:

```text
Score = Pair Frequency / (First Token Frequency × Second Token Frequency)
```

The pair with the highest score is selected for merging.

## Unknown Token

The `[UNK]` token is used when a word cannot be completely tokenized using the learned vocabulary.

Example:

```text
Input: unknownword
Output: [UNK]
```
